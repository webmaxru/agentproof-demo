# Submission media assets

This directory contains generated, sanitized media aids for the recording
workflow.

- `agentproof-silent-draft.mp4` is a silent, precomputed timing draft. It is
  not live evidence and carries a persistent `PRECOMPUTED / NOT LIVE` banner.
- `agentproof-silent-draft.srt` contains the matching cue-card captions.
- `agentproof-shot-log.template.md` is copied into a final shot log after the
  live take.

Replace the draft with the live GitHub/App recording before submission. Keep
the draft only as a clearly labeled editing reference.

The original draft and ten stills were retained from upstream snapshot
`47fdeeb665d930a599a3530958b8e62325647810`. All ten stills were visually checked
during migration: each has a persistent precomputed label and none includes the
historical repository owner. This is media inspection, not a human privacy
sign-off or a live workflow result.

New preparation assets are isolated in [recording-kit](recording-kit/README.md).
Their draft captions, templates, and silent timing reference do not constitute
a final live master, submitted exception, review, or approval.
